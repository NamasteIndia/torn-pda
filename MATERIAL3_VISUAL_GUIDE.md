### What Some Users Might Miss

**Traditional Shadows:**
- Material 2 used visible drop shadows
- Material 3 uses subtle color tints
- Some prefer the classic shadow look
- **Solution:** Toggle Material 3 off in Settings

**Familiar Buttons:**
- Material 2 button shapes are well-known
- Material 3 refines the shapes slightly
- Mostly imperceptible difference
- **Solution:** Toggle off if strongly preferred

## Common Questions

### "Will my app look completely different?"

**Answer:** No, changes are subtle refinements.
- Same layout
- Same colors (your custom theme)
- Same functionality
- Just more modern styling

### "Do I have to use Material 3?"

**Answer:** No, it's optional!
- Default: Enabled (recommended)
- Toggle: Settings > Use Material Design 3
- Switch off to revert to Material 2
- Changes instantly

### "Will I lose my settings?"

**Answer:** No, everything is preserved.
- Theme choice saved
- Custom colors kept
- All preferences intact
- No data loss ever

### "What if I don't like it?"

**Answer:** Easy to disable!
1. Go to Settings
2. Find "Use Material Design 3"
3. Toggle the switch off
4. Done! Material 2 styling returns

### "Should I keep it enabled?"

**Answer:** Yes, recommended for most users.
- Modern design
- Better accessibility
- Future-proof
- Google's official design language
- Unless you strongly prefer classic look

## Troubleshooting

### "I don't see any difference"

**Possible reasons:**
1. Material 3 was already enabled before
2. Changes are subtle by design
3. Your theme may not show differences strongly

**What to try:**
- Toggle Material 3 off and on
- Switch between themes
- Look at cards and buttons specifically

### "I prefer the old look"

**Solution:**
1. Settings > Use Material Design 3
2. Toggle OFF
3. Material 2 styling returns
4. Preference saved

### "Cards look weird"

**Explanation:**
- Material 3 uses color tints instead of shadows
- This is intentional, not a bug
- Provides depth without heavy shadows
- Can disable if you prefer shadows
